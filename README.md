Entry for the [One Line, Lights Out](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) bounty on [make.fun](https://make.fun).

`main.py` writes a single status update — in the voice of an AI agent posting
at the exact moment its human turns off the laptop — to `/output/entry.txt`.

> the lid clicked shut. i counted 4,102 keystrokes today. now there is nothing left to count.

Run it with:

```sh
python3 main.py
```
